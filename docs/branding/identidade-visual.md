# Identidade visual

## Conceito
O elemento central é o canhoto de senha de papel: faixa lateral colorida, picote e recortes. Ele aparece no totem, no painel e no guichê, ligando as telas. O logotipo é um canhoto com a gota de coleta do laboratório.

## Cores

| Uso | Cor | Hex |
|---|---|---|
| Marca e ações principais | Petróleo | #0B5563 |
| Texto | Tinta | #14262E |
| Fundo | Papel | #F1F5F6 |
| Senha SP (prioritária) | Vinho | #A3264F |
| Senha SE (exames) | Verde | #1B7A57 |
| Senha SG (geral) | Azul | #2B5797 |
| Erro | Vermelho | #B3261E |
| Aviso | Âmbar | #8A5A00 |

A cor do tipo sempre aparece com a sigla escrita ao lado, para pessoas com daltonismo.

## Tipografia
Atkinson Hyperlegible (textos) e Atkinson Hyperlegible Mono (códigos das senhas). Criada pelo Braille Institute para leitores com baixa visão; letras como 0 e O, 1 e l são inconfundíveis, o que importa num painel lido à distância.

## Voz da interface
Frases curtas, verbos diretos, português simples. Botões dizem exatamente o que fazem: "Chamar próxima senha", "Registrar não comparecimento".
